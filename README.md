## О проекте

Система управления заявками на переселение призраков. Оператор бюро видит карту города с шестью локациями, просматривает заявки, получает рекомендации алгоритма и подтверждает (или переопределяет) назначение.

**Все данные хранятся в `localStorage`** — прогресс сохраняется между сессиями. Бэкенда нет.

---

## Экраны

### 🗺️ Карта города
Интерактивная ночная карта с маркерами шести локаций. Привидения без места бродят по улицам как анимированные спрайты. Плавающая шапка с названием бюро. Клик на маркер — попап с характеристиками места.

### 👻 Заявки
Стопка карточек в стиле таро. Тяни карточку пальцем / свайпом для листания. Клик на карточку — 3D-переворот с детальной информацией: требования, дедлайн, тревожность, рекомендация алгоритма. Фильтры: все / без места / проблемные.

### 📊 Отчёт
Дашборд со статистикой: крупные числа, прогресс-бар расселения, список проблемных заявок, загруженность локаций.

### 📜 AI Worklog
Встроенный дневник разработки: инструменты, время, этапы, ключевые промпты, решения принятые самостоятельно.

## Алгоритм подбора

`src/logic/matcher.js` — пять шагов от заявки до рекомендации:

```
1. Блокер по дедлайну          — дедлайн истёк → impossible
2. Жёсткие блокеры             — переполнено, зеркала, люди, нет чердака...
3. Скоринг 0–100               — температура, свет, шум, сырость, тревожность, возраст
4. Выбор лучшего места         — сортировка по score, первое без блокеров
5. Ручное переопределение      — показывает конфликты, но не блокирует сохранение
```

Если ни одно место не проходит шаг 2 — статус `impossible` с перечислением причин по каждой локации.

---

## Edge cases

| Сценарий | Привидение | Результат |
|---|---|---|
| Просроченный дедлайн | Профессор Туман | `impossible` — «Дедлайн истёк» |
| Переполненное место | Типография (2/2) | Блокер при выборе |
| Зеркалобоязнь | Граф Морозий → Театр | Блокер «В месте есть зеркала» |
| Много требований | Баронесса Иней | Мало вариантов, часто `impossible` |
| Ручной конфликт | Любое → неподходящее | Предупреждение + «Всё равно заселить» |
| Все расселены | — | Отчёт 100%, пустая карточка заявок |

```
    │   └── CardFlipModal.jsx # 3D-переворот с детальной заявкой

    │   └── AssignModal.jsx   # выбор места + предупреждения о конфликтах
    ├── Report/
    │   └── Report.jsx        # дашборд со статистикой
    └── Worklog/
        └── Worklog.jsx       # AI Worklog (аккордеон)
```

## Запуск локально

```bash
git clone <repo-url>
cd ghost-bureau
npm install
npm run dev
```

Открыть [http://localhost:5173](http://localhost:5173)

```bash
npm run build   # сборка в dist/
npm run preview # предпросмотр продакшн-билда
```

## Деплой

Статический хостинг на Yandex Object Storage:

```bash
npm run build
aws s3 sync dist/ s3://ghost-bureau/ \
  --endpoint-url https://storage.yandexcloud.net \
  --delete --acl public-read --profile yandex
```
